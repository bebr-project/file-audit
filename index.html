Папка журнала

Здесь сохраняются записи аудита и служебные логи приложения.

C:\ProgramData\DocumentAudit

Чтобы выбрать другую папку на локальном диске сервера, откройте Choose-Log-Folder.cmd в папке приложения. Предыдущие записи аудита будут скопированы.

Важная особенность аудита WindowsПри сохранении файла Windows может создать несколько событий. Близкие события объединяются в журнале. Старые записи «Операция с именем» могли сопровождать переименование или удаление.
НАСТРОЙКА ИСТОЧНИКА

Настройка аудита папок

При первом запуске выберите папки для наблюдения и место для журнала.

  1. 1
    Откройте Start-Audit.cmd

    Дважды щёлкните файл в папке приложения. Windows попросит подтвердить права администратора.

    Node.js и другие программы устанавливать не нужно.
  2. 2
    Выберите папки с файлами

    В окне выбора укажите общий каталог. Можно добавить несколько папок.

    Для изменения списка папок откройте Configure-Audit.cmd.
  3. 3
    Выберите папку для журнала

    Можно оставить предложенный путь или выбрать папку на другом локальном диске. Позже её можно изменить через Choose-Log-Folder.cmd.

  4. 4
    Работайте с журналом

    Панель откроется автоматически. Сбор событий будет продолжаться в фоне после закрытия браузера и при перезапуске компьютера.

Приложение не отправляет данные во внешнюю сеть.
